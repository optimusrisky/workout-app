# ドメインルール

## PR(自己ベスト)の定義

- 判定基準は**最大重量のみ**とする。推定1RMやボリュームでの判定は行わない
  - 理由: 判定ロジックが最も単純で実装が軽い。推定1RM・ボリュームはR3のダッシュボード集計で別途見せればよく、PR判定に混ぜる必要はない
- 回数別PR(「5回で最も重い重量」など)は**持たない**
- **同種目の初回記録はPR扱いにしない**。「初記録」として別表示する
  - 理由: 比較対象がない状態で「PR達成!」と出すのは違和感がある。2回目以降の記録で初めてPR判定の対象にする

## 種目マスタの規模

- 共通の初期データ(マスタ)は**主要種目30〜50件程度**に絞る
  - ベンチプレス・スクワット・デッドリフト等、部位×器具で代表的なものだけを収録
  - ユーザーは独自種目を自由に追加できるため、マスタ自体が網羅的である必要はない
- 独自種目登録時は**部位・器具タイプ・記録形式を必須**にする(ボリューム計算・PR判定に必要)
- 種目の削除は**論理削除**(過去記録が参照しているため物理削除しない)
